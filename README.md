During the Haskell and Plutus course, I developed a solid understanding of functional programming principles using Haskell. The course covered topics such as recursion, pattern matching, higher-order functions, type classes, algebraic data types, functors, applicatives, monads, readers, writers, state, and monad transformers. I also learned how to write clean, type-safe, and modular code while solving practical programming problems. In the Plutus section, I gained hands-on experience with Cardano smart contract development, including on-chain and off-chain code, transaction validation, UTXO-based blockchain concepts, wallet interactions, and building decentralized applications (dApps). The course strengthened my problem-solving abilities and gave me practical experience in applying functional programming concepts to blockchain and smart contract development.
